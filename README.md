# Customer-Behavior-Analysis-
# 🛒 Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior using transactional data from **3,900 purchases** across multiple product categories. The objective is to identify customer spending patterns, product preferences, subscription trends, and purchasing behavior to support data-driven business decisions. The analysis combines **Python**, **SQL (PostgreSQL)**, and **Power BI** for end-to-end data analytics. 

---

## 🎯 Objectives

* Understand customer purchasing behavior.
* Identify high-value customer segments.
* Analyze subscription and discount usage patterns.
* Discover top-performing products and categories.
* Provide actionable business recommendations.
* Build an interactive dashboard for stakeholders.

## 🐍 Data Cleaning & Preprocessing (Python)

### Data Preparation

* Loaded dataset using Pandas.
* Performed exploratory analysis using:

  * `df.info()`
  * `df.describe()`

### Data Cleaning

* Identified missing values.
* Imputed missing Review Ratings using the median rating within each product category.

### Feature Engineering

* Created `age_group` column.
* Created `purchase_frequency_days` feature.

### Data Standardization

* Renamed columns using snake_case convention.

### Data Validation

* Checked redundancy between:

  * `discount_applied`
  * `promo_code_used`
* Removed redundant columns.

### Database Integration

* Connected Python with PostgreSQL.
* Loaded cleaned data into PostgreSQL for SQL-based business analysis.

## 🗄️ SQL Business Analysis

The following business questions were answered using PostgreSQL:

### 1. Revenue by Gender

Compared total revenue generated by male and female customers.

### 2. High-Spending Discount Users

Identified customers who used discounts and still spent above average.

### 3. Top 5 Products by Rating

Found products with the highest average customer ratings.

### 4. Shipping Type Comparison

Compared average spending across shipping methods.

### 5. Subscribers vs Non-Subscribers

Analyzed:

* Average purchase value
* Total revenue contribution

### 6. Discount-Dependent Products

Identified products with the highest percentage of discounted purchases.

### 7. Customer Segmentation

Classified customers into:

* New Customers
* Returning Customers
* Loyal Customers

### 8. Top 3 Products per Category

Determined the most purchased products in each category.

### 9. Repeat Buyers & Subscription Analysis

Evaluated whether frequent buyers are more likely to subscribe.

### 10. Revenue by Age Group

Measured revenue contribution across age segments.
